# シフトヘルパー

アルバイトの**シフト提出文づくり**と**年収の壁チェック**を1つにまとめたWebアプリです．

## 作った理由

2週間ごとのシフト提出で，毎回「日付・曜日・時間」を手で打っていました．
同時に，年末が近づくと「あと何日入ったら扶養の壁を超えるか」を給与明細から電卓で計算していました．
提出するシフトの情報があれば，年収の見込みも一緒に出せるはずだと考え，2つの作業を1つのアプリにまとめました．

## できること

- **シフト提出**
  - 曜日のボタンで2週間分をまとめて選び，カレンダーで1日ずつ調整できる
  - 曜日ごとのいつもの時間（例：木金土は 18-0）を自動で入れる
  - バイト先の形式どおりの提出文を作り，ワンタップでコピーできる
  - 周期がずれたら，シフトタブの「開始日」で期間の初日を変えられる（以後の2週間もその日から数える）
- **年収の壁**
  - 給与明細の額を入れると，その年に支給される額の見込みを出す（年収の壁は支給日で数えるため，勤務月と支給月のずれを考慮）
  - 見込み ＝ 明細で確定した額 ＋ 入力したシフトからの見込み ＋ 未入力の日を過去の平均ペースで仮定した額
  - 住民税・社会保険の扶養・親の扶養控除・所得税の壁ごとに，残りの額と「あと約何回入れるか」を表示する
  - 月額の目安を超えた月を強調する
- **設定**：名前，曜日ごとの時間，時給，深夜割増（22〜5時），壁の金額を自由に変えられる．JSONで書き出し・読み込みができる

## プライバシー

給与などのデータは**ブラウザの localStorage にだけ保存**し，サーバには送りません．
サーバを持たない静的サイトなので，GitHub Pages で無料で公開できます．

## 技術構成

| 項目 | 使用技術 |
|---|---|
| 画面 | React 19 + TypeScript |
| ビルド | Vite |
| テスト | Vitest（日付・深夜時間・提出文・年収見込みのロジック） |
| CI / 公開 | GitHub Actions → GitHub Pages |

計算ロジック（`src/core/`）は画面から切り離した純粋な関数にして，単体テストで確認しています．

```
src/
  core/        日付・期間・勤務時間・提出文・年収見込みの計算（画面に依存しない）
  components/  タブごとの画面
  storage.ts   localStorage への保存
tests/         core の単体テスト
```

## 動かし方

```bash
npm install
npm run dev     # 開発サーバ
npm test        # テスト
npm run build   # dist/ に出力
```

## 注意

年収の壁の金額は2026年分の目安です（給与収入のみ，23歳以上の学生を想定）．
年齢・自治体・制度改正で変わるため，公的な情報で確認してください．
